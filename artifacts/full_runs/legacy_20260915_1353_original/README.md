## 已知限制

1. 原始文件级直径 MAE/RMSE 在评估聚合时误用了真实直径标签，因此原始结果中的文件级回归误差为 0，不可作为有效指标。
2. 旧版文件划分没有充分平衡 Drive 与 Fan：101 文件方案中公共故障的训练集主要来自 Drive，验证集和测试集主要来自 Fan。
3. 本批次只有无重叠窗口、Cnn1d 和 CnnGru，不包含后续计划中的 CnnLstm、50% 重叠窗口和三套固定划分。

因此，本批次作为前期基线和实验过程记录保留，不纳入后续三套划分正式结果的平均值、标准差或最终模型排名。

## 目录内容

- `runs/`：10 组模型的最佳权重、最后检查点和训练历史
- `metrics/`：窗口级及文件级指标、逐文件预测和原始总表
- `figures/`：损失曲线、验证曲线、混淆矩阵和对比图
- `manifests/`：旧版文件划分与实验清单

- `metadata.csv`：数据文件审计元数据
- `logs/gpu_power.log`：训练期间的GPU功耗记录
