# CWRU 正式实验结果

这里是当前保留的 90 组正式结果：3 套固定数据划分 × 2 种窗口方式 × 5 种输入方案 × 3 种模型。

每组目录包含：

- `best_inference.pt`：验证集效果最好的模型，用于后续单文件预测；
- `metrics.json`：测试集指标；
- `history.json`：训练过程中的损失和准确率；
- `files.csv`：测试文件及其真实值、预测值；
- `figures/`：训练曲线和混淆矩阵。

顶层 `comparisons/` 保存 90 组结果的汇总表和对比图，`splits/` 保存本批次实际使用的划分快照。

旧的 10 组阶段性结果仍保存在 `../legacy_20260915_1353_original/`，没有删除，也不计入本批次汇总。

本目录中的 90 组结果是在本次训练规则调整前生成的历史结果；它们仍可用于汇报，实际使用的优化器、损失函数和学习率策略以 `run_config.json` 为准。
